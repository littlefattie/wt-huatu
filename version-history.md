# Versions

Following notes will mark why the library is versioned up:

## V1.4.0

- Add a lot features, include wire/net update and optimization
- a lot of error fixes and optimizations

## V1.3.4

- Refine Component fetch feature, make it async
- feature: make component wire able to connect to universal point
- Add more Arrow Marker Presets

## V1.3.3

- Make point series and path series indexable
- optimize shape intersection algorithm
- Add LineHeight feature for Label text

## V1.3.2

- Implement the feature of add arc to segmented path joints
- Minor bugfixes

## V1.3.1

- bugfixes
  - Make one-line define of path (not listing) possible
  - Check Coordinates system translation when dealing with Component
  - Add Job Id to avoid style collision between different files/svgs

## V1.3.0

- Features implemented
  - Polyline/Polygon points indexing possible
  - Dollar sign escaping
  - Path duplicating
  - Sub-path of LineSeg/Arc/Bezier2/Bezier3
  - More Intersection solving of shapes

## V1.2.2

- Add feature of DimMark (linear Dimension Mark)
- Make Angle Mark possible to have start arrow

## V1.2.1

- Add feature of Angle Mark
- Add feature of Drawing PointSeries directly

## V1.2.0

- Add MoveBy/RotateBy functionality fo transform paths/shapes to make new ones


## V1.1.1

- Some bug fix regarding Component placement/label adjusting
- Add CW/CCW support for triangle to path segments converting
- Add unified method of using the library in the main entry file

## V1.1.0

- New Version after a lot of features implemented. Too long time without version management, make a new minor version and start up the version history maintaining

## V1.0.0

- Initial Project creation and preliminary functions implementation
